 Recette de Cuisine

Ce projet est une mini page web qui présente différentes recettes de cuisine illustrées avec des images.

## Contenu du projet

- cuisine.html : page principale avec le contenu des recettes.
- style.css : fichier de style pour rendre la page plus jolie.
- Images : bouillon.jpg, haricot.jpg, poulet.jpg, tiep.jpg, recette.png.
